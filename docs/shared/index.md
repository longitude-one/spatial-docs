This section contains guidance and reference material for the entire
LongitudeOne Spatial ecosystem.

The [Documentation contribution workflow](./documentation-contribution-workflow.md)
explains how to write, validate, review and maintain documentation changes,
including standards citations and the documentation Definition of Done.

The [Portable Markdown publication contract](./portable-markdown-publication-contract.md)
defines the strict publication rules that keep generated HTML and Markdown
semantically equivalent while remaining portable and independently usable.

The [Spatial reference documentation architecture](./spatial-reference-documentation-architecture.md)
defines the Standards, Concepts and DBMS domains, their responsibilities,
and their relationship to versioned library documentation.

The [Markdown export example](./markdown-export-example.md) demonstrates content
preserved in both published representations.

The [Documentation migration rules](./documentation-migration-rules.md) define
how collected sources retain their ownership and version context when converted
into published pages, while the original migration corpus remains unchanged.

[Using documentation assets](./using-documentation-assets.md) shows how to add
and reference shared images, diagrams, schemas, examples and downloads.

The [Shared assets publication contract](./shared-assets-publication-contract.md)
defines supported formats, validation, the generated manifest and atomic publication.

[Validating generated documentation](./validating-generated-documentation.md)
explains the final publication gate, integrity manifests, reports and reproducibility checks.

[HTML search indexing and SEO validation](./html-seo-policy.md) describes canonical URLs, alternate representation indexing,
structured data and publication checks. The [HTML SEO audit](./html-seo-audit.md) records the Story 39 assessment.
