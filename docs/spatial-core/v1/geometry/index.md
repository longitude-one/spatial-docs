Spatial Core 1.x provides low-level technical primitives used by spatial
libraries. It classifies types and dimensions without supplying concrete
geometry values or choosing a serialization strategy.

- [Geometry type capabilities](./geometry-types.md): instantiability, components,
  topological dimensions and representation boundaries.
- [Spatial Core API overview](../index.md): coordinate dimensions, geographic
  axes, spatial models, units, reference-system kinds and byte order.
- [Geometry concepts](../../../concepts/geometries.md).
- [Coordinate and topological dimensions](../../../concepts/dimensions.md).
