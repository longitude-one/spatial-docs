Spatial Transformer is intended for dimensional, geometric, structural and geographic transformations of spatial objects. Its public repository currently
contains a project description rather than an implementation or package manifest.

## Planned responsibilities

- Dimensional transformations.
- Geometric and structural transformations.
- Geographic transformations.

## Requirements and compatibility

The public repository has no Composer manifest. PHP requirements, package dependencies and supported transformations have not been published.

The [roadmap](./roadmap.md) records plans; it does not establish an installable release or tested compatibility.

## API and usage

An API reference and installation instructions are not published yet. See the [project repository][repository] for its current scope.
