title: ISO standards
description: Introduces the ISO spatial standards included in the LongitudeOne reference scope.
---

This section introduces the ISO standards in LongitudeOne's spatial reference scope:

- ISO/IEC 13249-3;
- ISO 19107;
- ISO 19111;
- ISO 19136.

Detailed references will identify the relevant editions, requirements and
LongitudeOne support, limitations and extensions. Inclusion here does not imply
support or conformance.

See the [reference architecture](../../shared/spatial-reference-documentation-architecture.md#standards-reference) for authoring rules.
