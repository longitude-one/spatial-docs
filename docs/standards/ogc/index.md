This section introduces OGC specifications in LongitudeOne's spatial reference
scope, starting with Simple Features.

The [Simple Feature Access 1.2.1 reference](ogc-06-103r4.md) summarizes the
verified common architecture and records LongitudeOne support, limitations and
extensions per feature and implementation version. Inclusion here does not
imply whole-standard conformance.

See the [reference architecture](../../shared/spatial-reference-documentation-architecture.md#standards-reference) for authoring rules.
