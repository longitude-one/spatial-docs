This section introduces RFCs in LongitudeOne's spatial reference scope, starting
with RFC 7946 for GeoJSON.

The [RFC 7946 reference](rfc-7946.md) identifies the normative GeoJSON source
and records LongitudeOne's encoding support, limitations, caller responsibilities
and extensions. Inclusion here does not imply whole-standard conformance.

See the [reference architecture](../../shared/spatial-reference-documentation-architecture.md#standards-reference) for authoring rules.
