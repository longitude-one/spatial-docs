## Privacy and technical logs

The documentation application provides no user accounts, data collection forms
or newsletter. It uses no audience analytics, advertising or behavioral tracking.
Search runs locally in the browser, without an external search service.

The hosting infrastructure may produce technical access or security logs,
separately from any audience analytics operated by LongitudeOne. LongitudeOne
does not use these logs for audience analysis or visitor profiling. This page
does not presume the provider's practices, responsibilities or retention periods;
the contact details above can be used to request information applicable to this
hosting service.

## Cookies and local preferences

The application sets no cookies for audience analytics, advertising, tracking,
profiling or personalization. It therefore displays no consent banner for such
cookies, because it does not deploy them.

An explicit choice of light or dark theme may be remembered in the browser's
local storage. Local storage is not an HTTP cookie; this presentation preference
is not used to identify or track visitors. Rules governing access to a user's
terminal still apply to tracking technologies, including technologies that do
not use cookies.

Adding analytics, tracking technologies or data collection later requires a new
privacy and consent review. The need for a separate privacy policy will be
reassessed if the processing changes.
